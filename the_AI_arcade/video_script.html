AI Arcade — Sprint Review Video Script (~4:05)

[0:00–0:15] Open (Cmd + Shift + 5)

I'm the lead AI engineer on RetroMind Studios' new project — bringing classic board games back to life with built-in AI. Today it's Mastermind and Peg Solitaire, both solved with classical AI.

[0:15–1:20] Part 1 — The Detective Alibi (Mastermind)

Mastermind is a classic code-breaking game where players guess a 4-color sequence and receive feedback to refine their guesses. We chose this game because it's a perfectly constrained logical puzzle. Our demonstration shows a live attempt to uncover the secret code.

[Show: heatmap animation]

Each circle represents a possible color in a specific slot, with brightness indicating how many hypotheses support each choice. As options are ruled out, the circle color darkens.

After each guess, the AI checks all possible codes and asks a question: if this were the correct answer, would it produce the same result? If not, the candidate is eliminated. The pool of hypotheses shrinks with each cycle since we're eliminating options rather than just guessing.

[1:20–1:55] Part 2 — Rule-Based AI vs. LLMs

So why solve this with rule-based logic instead of an LLM? Mastermind is fully constrained — every rule is precise. On the other hand, an LLM is a statistical pattern-matcher. If you ask it to monitor a thousand hypotheses, it might repeat eliminated ones or suggest guesses that contradict actual feedback. For games with strict, precise rules, a rigid logic is required.

[1:55–3:50] Part 3 — The Custom Heuristic (A*)

Mastermind worked because feedback let us reason toward the answer. Peg Solitaire is different: pegs jump over each other until one remains, with no feedback along the way — the only way to know a sequence works is to search for it. That makes this a search problem, not a deduction problem.

[Show: nodes-expanded chart] Blind exploration comes at a price. BFS guarantees a 13-jump solution but expands 3,012 states. DFS is far cheaper, just 490, but it's gambling on a lucky branch. A* wins outright with a 98% reduction in compute cost — though raw node count is only half the story; the real bottleneck is memory.

[Show: memory/frontier chart] Breaking down frontier storage versus visited history: BFS hoards both, holding nearly 6,000 states in memory. DFS is lean at just 26 nodes, but still weighed down by nearly 500 visited states.

A* ranks every move with cost so far plus our best guess of what’s left. My heuristic adds two penalties to the baseline pegs-remaining count: one for isolated pegs with no neighbor to jump, one for dispersion.

One caveat: textbook A* requires an admissible heuristic to guarantee the shortest path. Mine breaks that rule on purpose. Normally that's risky, but every winning sequence here is exactly 13 jumps — there's no shorter path to miss. So we trade admissibility for speed, for free.

[3:50–4:05] Close (Cmd + Ctrl + Esc)

This project shows the power of matching the algorithm to the problem: Constraint Satisfaction for pure deduction, A* for targeted search. Fast, reliable AI, without a single neural net. Thanks for watching.
